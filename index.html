Setup notes

One-off setup for cloud sync (same pattern as the OTJ tool)
  1. Open the OTJ tool's index.html, find its clientId and tenantId values, and paste them into the CONFIG block at the top of this file (search for PASTE).
  2. In the Azure app registration, under Authentication, add a new redirect URI: https://littlepuddingssingin.github.io/planning/
  3. In the GitHub repo, create a folder called planning and upload this file as index.html plus a copy of msal-browser.min.js into that same folder.
  4. Sign in here as the manager and make any change; the folder - Little Puddings Planning will be created in your OneDrive with planning.json inside.
  5. Share that folder with each practitioner with Can edit rights (this is the step that makes sync work for them, exactly as with the OTJ folder).
  6. Each practitioner opens the page in a full browser tab (not a popped-out window) and signs in with their own groundedandcurious.co.uk account.
